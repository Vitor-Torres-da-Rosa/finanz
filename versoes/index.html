Esta página é da manutenção do app. Entre com a conta do administrador para vê-la.

Versões guardadas. A de cima é a que está no ar. Se uma atualização estragar alguma coisa, abra a de baixo — seus dados continuam os mesmos, porque ficam guardados no aparelho e não dentro da versão.

Feche o app nas outras abas antes. Cada versão guardada é um app inteiro apontando para o mesmo servidor. Duas abertas na mesma conta mandam versões diferentes dos seus dados e ficam desfazendo uma à outra — é assim que o saldo começa a mudar sozinho.

Por isso a versão guardada abre desconectada: ela enxerga os dados deste aparelho (dá para olhar e salvar um backup), mas não sincroniza sozinha. Para sincronizar é preciso entrar na conta ali dentro, de propósito.
